# Square Animation

A minimal vanilla JavaScript and CSS animation demo featuring an animated square element.

## Demo

Open `index.html` in your browser to see the square animation in action.

## Getting Started

### Prerequisites

No build tools or dependencies required — just a modern web browser.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/lorddrago12/Sqaure-Animation.git
   cd Sqaure-Animation
   ```

2. Open `index.html` directly in your browser:
   ```bash
   open index.html
   ```

   Or serve it locally with a dev server:
   ```bash
   npx serve .
   ```

## Project Structure

```
Sqaure-Animation/
├── index.html    # Main HTML file with the square element
├── script.js     # Animation logic
└── styles.css    # Styles and CSS keyframe animations
```

## How It Works

The project uses a single `<div class="square">` element as the animation target. CSS keyframes in `styles.css` define the animation, and `script.js` handles any dynamic behavior or interaction.

## Built With

- HTML5
- CSS3 (keyframe animations)
- Vanilla JavaScript
